# Source provenance and publication permissions

The **base URDF and STL geometry** came from a historical `mini_dog.zip` (Nov 2024) inside the user-supplied `Eliia Yermakov.zip` archive. That larger archive contains other persons' CV, reports, coursework and unrelated documents; **none of those personal files are included** in this prepared code package.

The historical package metadata identifies a maintainer named Maysoon; it does **not** contain an explicit redistribution license. The robot description also credits the SolidWorks-to-URDF exporter. If the geometry or ROS package was created by collaborators, their permission and credit are needed before public release.

The 2026 calibration and ROS 2 integration notes were recorded in the user's development conversations. The modified URDF, controller YAML and launch file in this bundle are **reconstructions from those notes**, not their last validated local source files. Do not represent this archive as a complete final production-ready robot or as solely authored by the GitHub maintainer.

Planned future Isaac Lab RL work will be integrated separately after obtaining the actual user-supplied files.
